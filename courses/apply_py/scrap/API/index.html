    Python网络数据采集专题：API接入与实战指南¶

    一、 为什么首选API进行数据采集？¶

    在Python网络数据采集中，直接调用公开API（Application Programming Interface）是最规范、最高效的方式。相比于传统的网页爬虫（Scrapy/BeautifulSoup），API具有以下核心优势：

    • 数据质量高：返回的通常是经过清洗的结构化数据（如JSON/XML），无需复杂的HTML解析。
    • 稳定性强：网站前端页面经常改版，但API接口通常会保持向后兼容。
    • 合规性好：天然符合平台的使用条款，对目标服务器的负载压力极小。
    • 实时性保障：数据延迟通常极低，适合需要高频更新的场景。

    二、 核心工具准备¶

    在开始之前，请确保你的Python环境已安装以下核心库：

    pip install requests pandas
    • requests：发送HTTP请求的神器，几行代码即可实现API调用。
    • pandas：用于将获取到的JSON数据转化为结构化表格（DataFrame），方便后续分析或入库。

    三、 WEB-API调用的基础语法¶

    几乎所有正规开放平台都会提供RESTful API。以下是使用requests库调用API的标准模板：

    import requests

url = "https://api.example.com/data"  # API接口地址
params = {"key1": "value1", "page": 1}  # 查询参数
headers = {
    "User-Agent": "MyDataCollector/1.0",  # 强烈建议添加，避免被拦截
    "Authorization": "Bearer YOUR_TOKEN"  # 若需鉴权则添加
}

response = requests.get(url, params=params, headers=headers)

if response.status_code == 200:
    data = response.json()  # 自动将JSON转为Python字典/列表
    print("获取数据成功：", data)
else:
    print(f"请求失败，状态码：{response.status_code}")

    四、 实用示例：从入门到进阶¶

    示例 1：获取实时天气数据（适合IoT/生活类应用）¶

    场景：调用OpenWeatherMap API获取指定城市的实时气象信息。

    import requests
import pandas as pd

API_KEY = '8abd518e58e48fb268a005f991cecb37'
CITY = 'Beijing'
url = f"http://api.openweathermap.org/data/2.5/weather?q={CITY}&appid={API_KEY}&units=metric"

response = requests.get(url)
data = response.json()

# 提取关键字段并转为DataFrame
weather_df = pd.DataFrame({
    '城市': [data['name']],
    '温度(℃)': [data['main']['temp']],
    '湿度(%)': [data['main']['humidity']],
    '天气状况': [data['weather'][0]['description']]
})
print(weather_df)

    示例 2：抓取股票历史K线（适合量化交易新手）¶

    场景：调用Alpha Vantage API获取股票每日收盘价等时序数据。

    import requests
import pandas as pd

API_KEY = '你的API密钥'
SYMBOL = 'IBM'
url = f"https://www.alphavantage.co/query?function=TIME_SERIES_DAILY&symbol={SYMBOL}&apikey={API_KEY}"

response = requests.get(url)
data = response.json()

# 解析时间序列字典
ts = data['Time Series (Daily)']
df = pd.DataFrame.from_dict(ts, orient='index').astype(float)
df.index = pd.to_datetime(df.index)
df = df.sort_index() # 按时间正序排列
print(df.head())

    示例 3：监测社交媒体热点（适合市场研究人员）¶

    场景：通过Twitter API v2搜索包含特定关键词的最新推文。

    import requests
import pandas as pd

BEARER_TOKEN = '你的Bearer Token'
headers = {"Authorization": f"Bearer {BEARER_TOKEN}"}
url = "https://api.twitter.com/2/tweets/search/recent?query=python&max_results=10"

response = requests.get(url, headers=headers)
data = response.json()

# 提取文本内容
tweets = [tweet['text'] for tweet in data['data']]
tweet_df = pd.DataFrame(tweets, columns=['推文内容'])
print(tweet_df.head())

    示例 4：工业级实战——供应链船舶轨迹追踪与入库¶

    场景：调用MarineTraffic API获取船舶位置，并进行数据库持久化存储。

    import requests
import pandas as pd
from sqlalchemy import create_engine

API_KEY = '你的API密钥'
url = f"https://services.marinetraffic.com/api/exportvesseltrack/{API_KEY}/v:2/shipid:241234560/protocol:jsono"

response = requests.get(url)
data = response.json()

df = pd.DataFrame(data)
df['timestamp'] = pd.to_datetime(df['lastUpdate'])

# 存入MySQL数据库
engine = create_engine('mysql+pymysql://user:pass@localhost/supply_chain')
df.to_sql('vessel_tracking', con=engine, if_exists='replace', index=False)
print("船舶轨迹数据入库成功！")

    五、 最佳实践注意¶

    1. 遵守速率限制（Rate Limit）：API提供商通常会限制请求频率（如每秒5次）。务必检查响应头中的 X-RateLimit-Remaining，遇到 429 Too Many Requests 时，应实现指数退避重试机制（Exponential Backoff）。
    2. 处理登录态与Token：对于需要授权的接口，不要每次都重新登录。应使用 requests.Session() 来复用Cookie，或在Header中携带长效的 Authorization: Bearer <token>。注意Token过期刷新逻辑。
    3. 应对CSRF防护：部分Web系统在POST请求前要求携带CSRF Token。需先GET获取登录页，解析出隐藏的 csrf_token 字段，再将其放入下一次POST请求的Body或Header中。
    4. 动态网页的API逆向：如果目标网站是SPA（单页应用），用requests抓取的HTML可能是空的。此时需打开浏览器开发者工具（F12 -> Network -> XHR/Fetch），观察翻页或滚动时触发的真实API接口，直接用Python请求该JSON接口，效率远高于Selenium。
    5. 合规与安全：永远不要采集用户隐私或未公开的商业敏感数据；设置真实的 User-Agent，不伪造请求来源；遵循平台的Robots协议和使用条款。
