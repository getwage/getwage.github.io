    正态分布概述¶

    在概率分析中最重要最常用的概率分布是正态分布(normal distribution)。正态分布又名高斯分布是以德国数学家卡尔.高斯的姓氏来命名的。

    正态分布是一种连续变量概率分布。这里假设随机变量$x$服从均值为$\mu$,标准差为$\sigma$的正态分布，此时正态分布的概率密度函数数学表达式为：$$p(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-{\frac {(x-\mu)^2}{2\sigma^2}}}$$

    期中$e$表示纳皮尔常数，有时候为了阅读方便该函数也可以写为：$$p(x) = \frac{1}{\sqrt{2\pi}\sigma}exp(-\frac {(x-\mu)^2}{2\sigma^2})$$

    $p(x)$可以理解为以$x$为输入获得一个概率密度的函数。$p(x)$表示的不是概率而是概率密度。这两者之间就像质量与密度的关系，概率为最终实现概率，概率密度则反映实现概率的环境。

    使用Python,可以将上式写成正态分布密度函数：

import matplotlib.pyplot as plt


def normal(x, mu=0, sigma=1):
    y = 1 / (np.sqrt(2 * np.pi) * sigma) * np.exp(-(x - mu)**2 / (2 * sigma**2))
    return y

    基于既有Python库的正态分布函数¶

    在 Python 中，处理正态分布有多种优秀的库可供选择。以下是几个最常用且功能强大的 Python 包：

    1. SciPy¶

    SciPy 是 Python 中最常用的科学计算库之一，其 stats 模块提供了极其丰富的统计分布函数。对于正态分布，它提供了 scipy.stats.norm 对象，这是一个非常全面且专业的工具。

    • 主要功能：支持计算概率密度函数（PDF）、累积分布函数（CDF）、逆累积分布函数（PPF），以及生成正态分布的随机样本（使用 rvs 函数）。

    2. NumPy¶

    NumPy 是 Python 中处理大规模多维数组和矩阵的基础数值计算库。虽然它不直接提供像 SciPy 那样完整的概率分布对象，但在生成随机数方面非常高效。

    • 主要功能：通过 numpy.random.normal 函数，可以方便且快速地生成指定均值和标准差的正态分布随机数样本。

    3. Python 标准库 (statistics)¶

    从 Python 3.8 版本开始，内置的 statistics 模块引入了 NormalDist 类，无需安装第三方库即可进行基础的正态分布计算。

    • 主要功能：支持基于样本数据估算均值和标准差、计算 PDF 和 CDF、计算逆累积分布函数（inv_cdf）、生成随机样本（samples），以及计算标准分（zscore）等。

    4. Statsmodels¶

    Statsmodels 是一个专注于统计建模和计量经济学的 Python 库。

    • 主要功能：除了基础的分布计算，它更侧重于拟合概率分布、进行假设检验以及构建复杂的统计模型。

    5. Matplotlib / Seaborn¶

    虽然它们主要是数据可视化库，但在处理正态分布时不可或缺。

    • 主要功能：可以结合上述库生成的数据，绘制正态分布的直方图、概率密度曲线等小，帮观地观察数据的分布特性。

    总结建议：

    • 如果需要进行专业的统计计算（如 PDF、CDF、假设检验），首选 SciPy。
    • 如果只需要快速生成大量正态分布的随机数用于模拟，NumPy 是最佳选择。
    • 如果不想安装第三方库且只需进行基础的正态分布分析，可以使用 Pytho怎么用这些库计算正态分布的PDF、CDF和生成随机样本？
